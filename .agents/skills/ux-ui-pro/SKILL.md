# UX/UI Pro for SNOTE

Use for SNOTE interface design, redesign, and interaction changes.

- Inspect the existing screen and nearby components before changing its layout.
- Prioritize notes, deadlines, and course context. Keep study content easy to scan and avoid decorative dashboard filler.
- Reuse the current React, CSS, and Lucide setup. Add a UI dependency only when the task cannot be handled cleanly with what is already present.
- Keep controls keyboard accessible, responsive, and clear at normal zoom. Respect reduced-motion preferences for nonessential animation.
- Preserve existing behavior unless the request changes it. Explain any interaction or information hierarchy change in concrete terms.
